# VeloCRM Changelog

## Version 1.0.0 — 2026-05-08

### Initial Release

- Full lead and customer CRM workflows
- Customer portal for invoice viewing, proposal responses, and profile updates
- Public no-login share links for invoices and proposals
- Payment gateway settings, checkout links, and signed webhook payment recording
- Per-invoice multi-currency support with exchange-rate reporting conversion
- Lead Kanban pipeline, CSV import, and CSV import template
- Customer notes and attachment management
- Invoice, invoice items, payment recording, recurring invoices, and PDF generation
- Proposal management and PDF generation
- Task board, task list, and calendar views
- Dashboard widgets and reports with CSV export
- Admin user management with active and inactive accounts
- Admin settings for branding, SMTP, regional settings, and Envato purchase code
- English and Thai localization support
- Thai-compatible DomPDF font configuration
- Email templates, notifications, and scheduled reminders
- Soft delete and restore workflows for core resources
- Activity logging and role-based access control
- Installer wizard for requirements, database, company setup, SMTP, regional settings, and admin account creation
- HTML documentation pack, buyer readme, and license summary
- Demo seed and reset Artisan commands for marketplace demo sites
- Security hardening for authorization, upload validation, rate limiting, and mass-assignment protection
