REST API

Authentication

VeloCRM uses Laravel Sanctum bearer tokens. Admin and Staff users can create a token in Admin > Settings > API Tokens or request one with the login endpoint.

curl -X POST https://your-domain.com/api/login \
  -H "Accept: application/json" \
  -d "email=admin@example.com" \
  -d "password=your-password" \
  -d "device_name=Integration"

Send the returned token on later requests:

Authorization: Bearer YOUR_TOKEN_HERE

Endpoints

MethodPathDescription
POST/api/loginCreate a Sanctum bearer token.
GET/api/leadsList leads. Supports status, search, and per_page.
POST/api/leadsCreate a lead.
GET/api/leads/{id}Show a lead.
PUT/api/leads/{id}Update a lead.
DELETE/api/leads/{id}Soft delete a lead.
GET/api/customersList customers. Supports search and per_page.
POST/api/customersCreate a customer.
GET/api/customers/{id}Show a customer.
PUT/api/customers/{id}Update a customer.
DELETE/api/customers/{id}Soft delete a customer.
GET/api/invoicesList invoices. Supports status, customer_id, and per_page.
POST/api/invoicesCreate an invoice with line items. Optional item wht_rate supports 0, 1, 2, 3, 5, 10, and 15.
GET/api/invoices/{id}Show an invoice with customer and items.
PUT/api/invoices/{id}Update an invoice and replace line items.
DELETE/api/invoices/{id}Soft delete an invoice.
GET/api/reports/summarySummary report. Supports start_date and end_date.

Create Lead Example

curl -X POST https://your-domain.com/api/leads \
  -H "Accept: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -d "name=Acme Prospect" \
  -d "email=lead@example.com" \
  -d "status=New" \
  -d "source=Website" \
  -d "value=2500"

Create Invoice Example

curl -X POST https://your-domain.com/api/invoices \
  -H "Accept: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -H "Content-Type: application/json" \
  -d '{
    "number": "INV-1001",
    "customer_id": 1,
    "invoice_date": "2026-05-11",
    "due_date": "2026-05-25",
    "status": "Draft",
    "currency": "THB",
    "exchange_rate": 1,
    "tax_total": 350,
    "items": [{"description": "Consulting", "quantity": 1, "unit_price": 5000, "wht_rate": 3}]
  }'

Invoice Totals

Invoice responses include subtotal, tax_total, wht_total, discount, total, amount_paid, and balance_due. Line items include wht_rate and calculated wht_amount.

Authorization

API access reuses the same policies as the web application. Admin users can access all CRM records. Staff users are limited by the existing ownership rules.
