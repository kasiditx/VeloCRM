Buyer Documentation

VeloCRM is a self-hosted CRM for SME sales teams. It includes leads, customers, invoices, proposals, tasks, calendar, reports, recurring invoices, PDF documents, English/Thai localization, and a browser installer.

Start Here

  1. Read Installation.
  2. Complete company, SMTP, and regional setup.
  3. Create the admin account.
  4. Run the scheduler cron if you use reminders or recurring invoices.
  5. Open Settings and send a test email.
