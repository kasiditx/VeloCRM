Configuration

Branding

Open Admin > Settings > Branding to upload a logo, favicon, and primary color. Uploads are stored in public/uploads/branding.

SMTP

Open Admin > Settings > SMTP. Enter host, port, encryption, username, password, sender email, and sender name. Use the test email action before relying on notifications.

Regional

Set currency code, currency symbol, and date format. These settings drive list pages, dashboards, reports, and PDF documents.

Language

The application supports English and Thai. Users can switch language from the navigation bar.
