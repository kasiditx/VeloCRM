FAQ

The installer says a folder is not writable

Make storage/, bootstrap/cache/, and public/uploads/ writable.

Email is not sending

Check SMTP values in Admin Settings and send a test email. Some hosts block outbound SMTP or require the full mailbox address as username.

Recurring invoices are not generated

Confirm the invoice is recurring, next_recurring_date is due, and the scheduler cron runs every minute.

Thai PDF text does not render correctly

Confirm DomPDF font files are present in the package and rebuild font cache if your host changes font paths.
