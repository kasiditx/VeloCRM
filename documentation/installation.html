Installation

Server Requirements

  • PHP 8.2 or newer
  • MySQL 8 or MariaDB compatible database
  • PHP extensions: bcmath, ctype, fileinfo, gd or imagick, mbstring, openssl, pdo_mysql, tokenizer, xml, zip
  • Writable folders: storage/, bootstrap/cache/, public/uploads/

Browser Installer

  1. Upload the package to your server.
  2. Point the domain document root to public/.
  3. Create an empty database and database user.
  4. Open https://your-domain.com/install.
  5. Complete requirements, database, company setup, SMTP setup, regional setup, and admin account creation.
  6. Finalize installation and sign in.

After Install Checklist

  • Upload logo and favicon.
  • Send an SMTP test email.
  • Create or import leads.
  • Create the first invoice and verify PDF output.
  • Configure scheduler cron.
