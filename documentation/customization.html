Customization

Safe Areas

Prefer Admin Settings for company name, logo, colors, SMTP, locale, currency, and date format before editing code.

Code Changes

If you modify Blade or Livewire files, keep a backup and document every changed file before upgrading. Avoid editing migrations that already ran in production.

Localization

Translation strings live in lang/en.json and lang/th.json. Keep both files aligned when adding copy.
