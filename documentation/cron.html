Cron Jobs

Recurring invoices and overdue reminders use Laravel Scheduler. Add this cron command on the server:

* * * * * php /path/to/velocrm/artisan schedule:run >> /dev/null 2>&1

cPanel

Use the Cron Jobs tool and update the PHP binary path if your hosting provider requires a custom path.
