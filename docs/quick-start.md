# Quick Start

## 5-Minute Checklist

1. Sign in with the admin account.
2. Open `Admin > Settings`.
3. Review:
   - company name
   - site title
   - SMTP sender
   - currency symbol
   - date format
4. Create staff users if needed.
5. Add your first lead or import leads from CSV.
6. Convert a lead to a customer.
7. Create an invoice or proposal.
8. Open the dashboard and reports pages to confirm data flow.

## Recommended First Records

- one lead
- one customer
- one invoice
- one proposal
- one task

This confirms the main CRM flow works end to end on the target hosting environment.
