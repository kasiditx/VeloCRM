# Support Policy

## Included Support

- installation guidance
- configuration guidance
- bug clarification for stock VeloCRM behavior
- help locating documented settings

## Not Included

- free custom feature development
- server administration outside VeloCRM requirements
- third-party SMTP or hosting support beyond basic configuration guidance
- modifications to heavily customized codebases

## Before Requesting Support

- confirm server requirements
- confirm cron configuration
- confirm SMTP settings
- include screenshots and exact error messages
- include application version and reproduction steps
