# CodeCanyon Pre-Submission Checklist

## Product Validation

- Verify installer completes on a fresh database
- Verify admin login works immediately after install
- Verify SMTP test email succeeds
- Verify invoice PDF branding is correct
- Verify proposal PDF branding is correct
- Verify recurring invoices generate after scheduler runs
- Verify overdue reminders send after scheduler runs

## Marketplace Package

- Include buyer documentation
- Include changelog
- Include support policy
- Include screenshots for dashboard, leads, customers, invoices, reports, settings, and installer
- Remove any personal/demo credentials from the package

## Hosting Notes

- Confirm cron setup instructions are included
- Confirm writable folder guidance is included
- Confirm shared-hosting fallback behavior is documented
